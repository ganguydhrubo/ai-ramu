What AI RAMU does

Everything below ships in the open-source engine AI RAMU is built on and is configured from one dashboard on your machine.

  • 💬

    Chat on WhatsApp

    Pair once with WhatsApp's Linked devices QR code. Telegram, Discord, Slack and other channels are available too.

  • 🧠

    Your choice of model

    Run a local model with Ollama, LM Studio or vLLM, or connect a provider such as Google Gemini, OpenRouter, OpenAI or Anthropic.

  • 🌐

    Browser automation

    A dedicated Chrome/Chromium profile the agent can drive to look things up and fill in pages.

  • ⏰

    Scheduled jobs

    Recurring tasks with cron schedules — reminders, summaries, checks — that report back to your chat.

  • 🗂️

    Files, tools & skills

    Workspace files, shell commands with approval prompts, plugins and skills you can turn on or off.

  • 🖥️

    Local dashboard

    Chat, sessions, channels, schedules, logs and health checks at 127.0.0.1:18789.

Set up in four steps

About 10 minutes on a typical home connection. Windows users can double-click START_AI_RAMU.bat after step 2.

  1. Install Node.js 24 LTS

    From nodejs.org, or on Windows:

    winget install OpenJS.NodeJS.LTS

  2. Download AI RAMU

    git clone https://github.com/ganguydhrubo/ai-ramu
cd ai-ramu
npm install

  3. Start & pick a model

    npm start
npm run onboard

    Starts the gateway, opens the dashboard, then lets you choose a model. Choose Ollama for a fully local, key-free setup.

  4. Connect WhatsApp

    npm run whatsapp

    On your phone: WhatsApp → Settings → Linked devices → Link a device, then scan the QR code shown in the terminal.

Free & open, honestly

  • Free software. MIT licensed, no paid tiers, no feature gates.
  • Runs on your machine. Config, sessions and WhatsApp credentials stay in your user folder.
  • Your model, your bill. Local models cost nothing extra. Cloud providers have their own pricing and free-tier limits.
  • Your WhatsApp account. AI RAMU links as one of your devices, so WhatsApp's own terms apply.
  • Built in the open. AI RAMU packages the MIT-licensed OpenClaw engine with its own branding, launcher and update checks; upstream notices are kept in the repository.
